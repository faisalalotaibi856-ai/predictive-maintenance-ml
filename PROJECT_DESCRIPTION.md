# Project Descriptions

## GitHub repository short description

Machine-failure classification on UCI AI4I with scikit-learn pipelines, leakage checks, stratified cross-validation, validation-based thresholds, measured evaluation, and reproducible inference.

## LinkedIn project description

An academic machine-learning project investigating machine-failure classification using the official UCI AI4I 2020 dataset. The implementation includes a data-quality and leakage audit, training-only exploratory analysis, preprocessing pipelines, comparison of logistic regression, random forest and histogram gradient boosting, and a small cross-validated tuning search.

The project handles the rare failure class through appropriate metrics and evaluated class-weight settings. A separate validation partition selects the decision threshold, followed by one final test evaluation. Supporting deliverables include permutation importance, an executed notebook, command-line training and prediction, automated tests, and reproducible reports.

The dataset is synthetic, and the target describes failure at the observation. This work does not claim industrial deployment, advance-warning performance, or measured business savings.
